About Notepad++ (macOS Edition)

Notepad++ (macOS Edition) v1.0.0

High performance editor with Scintilla/Monaco engine & Plugins Ecosystem

Built-in power plugins enabled:

  • Compare Plugin: Side-by-side visual diff with navigation
  • XML Tools: Pretty print, linearize, syntax validator, XPath evaluator
  • JSON Tools: Formatter, minifier, syntax checker, tree viewer
  • TextFX Tools: Sort, deduplicate, casing, base64/url encode
  • NppExec: Live code/script runner (Node, Python, Bash) with console

Custom plugins can be dropped into the user's plugin folder or installed from the Plugins Admin marketplace.
